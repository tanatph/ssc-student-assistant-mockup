# ระบบนิสิตช่วยงาน ศูนย์กีฬาสิรินธร — เวอร์ชันทดสอบ

สร้างอัตโนมัติจากโปรเจกต์หลักด้วย `npm run build:mock` (29 ต.ค. 2569 14:49) — อย่าแก้ไฟล์ในโฟลเดอร์นี้โดยตรง

- ใช้ข้อมูลตัวอย่าง เก็บในเบราว์เซอร์ของผู้ทดสอบเท่านั้น ไม่เชื่อมกับ Google Sheet จริง
- บัญชีทดลองดูได้ที่หน้าเข้าสู่ระบบ (รหัสผ่าน demo1234)
- แถบสลับบทบาท (ลากย้าย/ย่อได้): สลับเป็นแอดมิน ผู้สมัคร หรือนิสิตช่วยงานฝ่ายละ 10 คนได้ทันที
- ปุ่ม "ล้างข้อมูลทดสอบ" ในแถบ = เริ่มใหม่ด้วยข้อมูลตัวอย่าง
